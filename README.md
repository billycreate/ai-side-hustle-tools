# AI副業ツール研究ノート

初心者向けにAI、副業、発信ツールを紹介するアフィリエイトサイトのスターターです。

## 公開方法

1. GitHubで新しいリポジトリを作る
2. このフォルダのファイルをアップロードする
3. リポジトリの Settings > Pages で `main` ブランチのルートを公開元にする
4. 公開URLをXプロフィールに貼る

## 最初にやること

- `index.html` のサイト名や文章を自分の言葉に直す
- `privacy.html` の広告表記を確認する
- ASPに登録したら記事内にリンクを追加する
- Xで毎日1つ、試したことを投稿する

## 注意

アフィリエイトリンクを貼るページや投稿では、広告であることが読者にわかる表示を入れてください。
