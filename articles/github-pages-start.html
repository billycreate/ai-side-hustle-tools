Publishing

無料で発信拠点を作るならGitHub Pagesからでいい理由

最初からサーバー代をかけるより、まずは無料で公開して、続けられるかを確認するのが大切です。

広告についてこの記事にはアフィリエイト広告を含む場合があります。

費用をかけずに公開できる

GitHub Pagesなら静的なHTMLサイトを無料で公開できます。最初の目的は、収益化よりも記事を書く習慣と読者の反応を作ることです。

後から移行しやすい

記事テーマが固まってから、WordPressや独自ドメインを検討しても遅くありません。最初に大きく作り込みすぎないほうが続けやすいです。

注意点

HTMLの編集に少し慣れが必要です。画像やリンクを追加するときは、表示崩れと広告表記の入れ忘れを確認します。
